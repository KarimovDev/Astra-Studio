Релиз версии 2.0 AstraChat

23 сентября, 2026

Второй крупный релиз AstraChat: полноценная работа с RAG в проектах и агентах, конструктор агентов со скиллами, плагинами и артефактами, галереи, OCR, ролевая модель шаринга и обновлённый визуальный слой интерфейса.

Retrieval Augmented Generation (RAG)

Где работает RAG

  • Проекты — база документов проекта: загрузка файлов, поиск по ним в проектном чате, отдельные настройки RAG на уровне проекта.
  • Агенты — документы агента (контекстная база знаний агента): загрузка в конструкторе агента, поиск при работе с этим агентом, отдельные настройки RAG на уровне агента.
  • Общая библиотека памяти — отдельный контур; стратегия чанкования и модели для неё задаются административно и не переопределяются настройками проекта/агента.

Стратегии поиска

Доступны режим автоматического выбора и четыре явные стратегии:

  • Векторный — поиск по смыслу (близкие формулировки, пересказы, свободные вопросы).
  • Лексический — поиск по точным словам и формулировкам (коды, номера, артикулы, имена, цитаты, термины).
  • Гибридный — одновременный смысловой и точный поиск; универсальный режим для повседневной работы.
  • Графовый — релевантные фрагменты плюс связанный контекст (сравнения, причинно-следственные цепочки, ответы «размазанные» по нескольким кускам документа).
  • Автоматический выбор — система сама выбирает одну из четырёх стратегий по формулировке вопроса.

Стратегии чанкования

Действуют для документов проекта и агента (не для общей библиотеки):

  • Фиксированное — нарезка на чанки фиксированной длины; предсказуемо по размеру и скорости.
  • По разметке — ориентация на структуру (заголовки, списки, секции); удобно для wiki и markdown-документации.
  • По разделителям — абзацы, переносы, знаки и служебные маркеры.
  • Семантическое — сохранение цельных смысловых блоков внутри чанка.
  • Иерархическое — сначала крупные смысловые блоки, затем более мелкие фрагменты (универсальный режим для смешанных корпусов).

Гибкие настройки чанкования и поиска

В настройках RAG проекта/агента доступны:

Параметр Назначение Диапазон / по умолчанию
Количество чанков (K) Сколько фрагментов подмешивать в промпт 1–64 (по умолчанию 5)
Размер чанка Целевой размер чанка в символах 200–8000 (по умолчанию 1000)
Размер перекрытия Перекрытие соседних чанков в символах 0–2000 (по умолчанию 200)
Порог схожести Минимальный порог релевантности (0 — без фильтрации) 0–1

Методы улучшения запросов

  • Agentic RAG — в режиме чата «Агент» модель сама запрашивает документы инструментом; при выключении фрагменты подмешиваются заранее.
  • Переранжирование — cross-encoder переупорядочивает найденные чанки; отдельно задаётся Top-N после реранкинга (1–64, по умолчанию 5).
  • Исправление опечаток в запросе — короткий вызов LLM до поиска.
  • Несколько формулировок (multi-query) — 3–5 альтернативных формулировок, поиск по каждой, объединение результатов.
  • HyDE — гипотетический ответ для улучшения векторного поиска (не подставляет факты из файлов).

Модели embedding и reranker

  • Интеграция с embedding и reranker моделями домена CORSUR.
  • Интеграция с embedding и reranker моделями домена PHOENIX.
  • Модели выбираются в настройках RAG для проекта или агента; общая библиотека использует свои модели, задаваемые администратором.

Форматы документов в RAG

PDF, DOC/DOCX/DOCM, XLS/XLSX/XLSM, TXT, MD, CSV, LOG, RTF, а также изображения JPG/JPEG/PNG/WEBP/BMP (с OCR).

Агенты

Создание и настройка

  • Конструктор агентов: имя, описание, системные инструкции.
  • Подключение к агенту:
    • Skills — включение и выбор скиллов;
    • Плагины — плагины из галереи;
    • Артефакты — визуализация HTML / Mermaid / SVG и presentation viewer; опционально компоненты shadcn/ui или режим пользовательского промпта артефактов;
    • RAG — документы агента и полный набор настроек поиска, чанкования и моделей.
  • Публикация агента в галерею и использование агентов из галереи.

Совместный доступ

  • Владелец — полное управление, в том числе удаление и повторный шаринг;
  • Редактор — просмотр, использование и изменение (без удаления и повторного шаринга);
  • Зритель — только просмотр и использование, без изменения настроек.

Галерея

  • Галерея агентов — просмотр публичных агентов, поиск, закладки, добавление к себе и запуск.
  • Галерея скиллов — публикация и просмотр публичных скиллов.
  • Галерея плагинов — каталог плагинов для подключения к агентам.

Скиллы

  • Создание и редактирование скиллов.
  • Экспорт и импорт скиллов (JSON / текстовые форматы).
  • Шаринг скиллов с ролями Владелец / Редактор / Зритель (аналогично агентам).
  • Публикация в галерею скиллов.
  • Готовый скилл «Презентация ГПБ» (раздел Skills) для генерации презентаций в формате АО «Газпромбанк» с отдельным отображением в чате.

Optical Character Recognition (OCR)

  • Распознавание текста с изображений, прикреплённых через кнопку «+» в поле ввода сообщения.
  • Распознавание текста с изображений, загружаемых в RAG (проект, агент, библиотека).
  • Поддерживаемые форматы изображений: PDF, JPG, JPEG, PNG, WEBP, BMP.

Файлы через кнопку «+»

Прикрепление к сообщению (файл сохраняется и передаётся в модель без индексации в RAG):

  • Лимит размера: до 20 МБ на файл. Для более крупных документов рекомендуется загрузка в агентный или проектный RAG.
  • Форматы документов: PDF, Word (.docx, .docm), Excel (.xlsx, .xls, .xlsm), текст (.txt, .md, .log, .rtf).
  • Форматы изображений: .jpg, .jpeg, .png, .webp, .gif, .bmp (для изображений доступен OCR).

Роли

  • Ролевая модель для агентов: Владелец / Редактор / Зритель.
  • Ролевая модель для скиллов: Владелец / Редактор / Зритель.
  • Разграничение прав на просмотр, использование, редактирование, удаление и повторный шаринг.

Артефакты

При включённых артефактах у агента (или при активном presentation-скилле) в чате отображается визуализация:

  • HTML — интерактивный предпросмотр HTML-страниц и виджетов;
  • Mermaid — диаграммы и схемы (flowchart, sequence, pie, xychart и др.);
  • дополнительно поддерживаются SVG и presentation viewer для презентаций (в т.ч. в корпоративном формате Газпромбанка).

Доступны режимы:

  • стандартный промпт артефактов;
  • режим пользовательского промпта (системный промпт артефактов не используется — инструкции задаются вручную).

Дизайн

  • Переработан выбор цвета боковых панелей (пресеты и пользовательский цвет, корректный контраст текста и иконок на светлых и тёмных панелях).
  • Переработан дизайн иконок в интерфейсе (навигация, списки, элементы сайдбара).
